# Wenrui Li - Psychotherapist Website

A clean, minimalist, and calming personal website for a psychotherapist, inspired by the design of Ally Therapy. The website features bilingual support (English and Chinese) with smooth animations and responsive design.

## Features

### 🎨 Design
- **Clean & Minimalist**: Soft, neutral color palette with calming aesthetics
- **Responsive**: Mobile-friendly design that works on all screen sizes
- **Smooth Animations**: Fade-ins and card transitions for enhanced user experience
- **Inspired by Ally Therapy**: Professional and trustworthy design approach

### 🌐 Bilingual Support
- **English & Chinese**: Complete content available in both languages
- **Language Toggle**: Easy switching between languages in the header
- **Seamless Translation**: All static content properly translated

### 📱 Sections
1. **Home**: Hero section with therapist introduction and key statistics
2. **About**: Detailed biography and credentials
3. **Services**: Four main therapy approaches (IFS, EMDR, Somatic Therapy, CBT)
4. **FAQ**: Common questions about therapy process, insurance, and fees
5. **Contact**: Contact form and contact information

### ⚡ Functionality
- **Client-side Routing**: Smooth navigation between sections without page reloads
- **Contact Form**: Functional contact form with validation
- **Responsive Navigation**: Mobile-optimized navigation menu
- **Smooth Scrolling**: Enhanced user experience with smooth transitions

## Technology Stack

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript**: Vanilla JS for interactivity and language switching
- **Google Fonts**: Inter font family for clean typography

## Color Palette

- **Primary Green**: `#7fb069` (calming, professional)
- **Text Dark**: `#2c3e50` (readable, professional)
- **Text Light**: `#6c757d` (subtle, accessible)
- **Background**: `#fafafa` (soft, clean)
- **White**: `#ffffff` (clean cards and sections)

## Customization

### Content Updates
- Edit the HTML file to update therapist information
- Modify text content in both English and Chinese
- Update contact information and credentials

### Styling Changes
- Modify `styles.css` to change colors, fonts, or layout
- The color variables are defined at the top of the CSS file
- Responsive breakpoints are clearly marked

### Language Support
- Add new languages by extending the `translations` object in `script.js`
- Follow the existing pattern for data attributes in HTML
